# WorkFlowHub Enterprise Platform

WorkFlowHub is an enterprise workflow management platform built as a full-stack learning and portfolio project.

## Current Scope

The system will include:

- User authentication
- Role-based access
- Employee management
- Department management
- Task management
- Leave approval workflow
- Document management
- Notifications
- Audit logs
- Reports
- Dashboard
- Docker deployment
- Cloud and Kubernetes learning phase

## Tech Stack

- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- Angular
- Docker
- Redis
- Azure
- Kubernetes

## Current Backend Progress

- Project structure created
- Initial entities created
- EF Core migrations created
- SQL Server database created
- Initial tables created
